# Grand Dine — Premium Restaurant Website

A multi-page restaurant website demo built with **HTML, CSS, and vanilla JavaScript**. No framework or package installation is required.

## Run the project
1. Download and extract `grand-dine-premium.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. For best results, keep an internet connection for Google Fonts and Unsplash photos.

## Pages included
- `index.html` — luxury landing page and featured dishes
- `menu.html` — menu search, category filters, add-to-cart
- `reservations.html` — validated table request form
- `cart.html` — quantity controls, totals, promo code `GRAND10`
- `checkout.html` — demo checkout
- `bill.html` — separate itemized invoice and print/save-to-PDF
- `order-tracking.html` — demo order timeline
- `order-history.html` — saved demo orders
- `profile.html` — local demo profile
- `about.html`, `gallery.html`, `offers.html`, `contact.html`, `faq.html`

## Important limitations
This is a frontend-only academic demo. Reservations are not sent to a restaurant; order tracking is simulated; profile and order data are stored in the current browser; and no real payment is taken. Real user accounts, online payment, restaurant availability, emails, and live delivery tracking require a secure backend and/or third-party providers. Restaurant content, contact details, prices, and photos are sample content and should be updated before any real use.

## Suggested presentation
Explain that HTML provides page structure, CSS handles responsive styling and animation, and JavaScript powers menu filtering, cart actions, form validation, local storage, order history, and invoice calculations.
